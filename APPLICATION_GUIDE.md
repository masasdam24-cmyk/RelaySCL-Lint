# Application guide: OpenAI Codex for Open Source

Official application: https://openai.com/form/codex-for-oss/

The program currently reviews maintainers of **active open-source projects** and considers meaningful usage, ecosystem importance, and evidence of ongoing maintenance. A freshly published project can be submitted, but approval is **not guaranteed** and is less compelling without demonstrated use. Never invent repository stars, users, contributions, or maintenance activity.

## Repository publication checklist

1. Create a **public** GitHub repo named `RelaySCL-Lint`.
2. Upload the contents of this folder, preserving `.github/workflows/ci.yml`.
3. Confirm GitHub Actions tests are green.
4. Add a brief genuine project description, topics: `iec61850`, `scl`, `goose`, `relay-protection`, `lint`, `python`.
5. Cut a GitHub Release `v0.1.0` with release notes that accurately describe the tested capabilities.
6. Invite feedback in legitimate technical communities; do not manufacture endorsements.
7. Keep personal account details, proprietary SCL/CID files and employer materials out of the repository.

## Application fields

- First and last name: your actual name.
- Email: the one associated with the ChatGPT account you want considered.
- GitHub username: your **real** publicly visible GitHub username.
- GitHub repository URL: actual public repository link (after publication).
- Describe your role and relevance: a short, factual summary (limit shown on official form: 500 characters).

### Example summary, edit to fit verified facts

> I am the creator and maintainer of RelaySCL-Lint, an open-source, offline IEC 61850 SCL/GOOSE configuration checker for protection-and-control workflows. I maintain its diagnostics, automated tests, documentation, and releases. Codex would help review contributions, improve test coverage, and keep the tool reliable. The project is newly released; usage is still being established.

Do not say the project is "widely adopted" or used in production without evidence.

## Important

The official program covers six months of ChatGPT Pro for **selected** maintainers. There is no guarantee of acceptance or an announced fixed response time. Review is rolling.
